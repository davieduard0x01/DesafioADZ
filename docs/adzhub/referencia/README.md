# Referência visual — blueprint da própria AdzHub

Quadros extraídos da gravação da página do desafio (`adzhub.com.br/vagas/desafio-harness`),
seção **"ANIMAÇÃO BLUEPRINT DE EXEMPLO"**. É o mockup que a própria AdzHub desenhou do
chat agêntico. A interface do protótipo segue esta linguagem visual.

- `blueprint-topo.jpg` — cabeçalho do AdzChat, bolha do usuário, primeiras linhas do trace
- `blueprint-completo.jpg` — cartão pausado, linhas de tool, resposta final, campo de entrada
  e a **legenda do fluxo** (`intent → raciocínio → tool → observação → ação → resposta`)
